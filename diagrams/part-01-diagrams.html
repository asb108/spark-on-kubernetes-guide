5. Integrated Orchestration: Submission Flow

Complete Submission Flow

sequenceDiagram participant You participant SparkSubmit participant K8sAPI as K8s API participant Scheduler participant Kubelet participant Driver participant Executor You->>SparkSubmit: spark-submit --master k8s:// SparkSubmit->>K8sAPI: POST /pods (Create Driver) K8sAPI->>Scheduler: Schedule Pod Scheduler->>K8sAPI: Assign Node Kubelet->>Driver: Start container Driver->>K8sAPI: POST /pods (Create Executors) Kubelet->>Executor: Start executors Executor->>Driver: Register Driver->>Executor: Send Tasks Executor->>Driver: Task Results Driver->>K8sAPI: DELETE executor pods

Spark Submit Arguments

Argument Meaning
--master k8s://... Use Kubernetes as cluster manager (API server URL)
--deploy-mode cluster Run driver inside K8s (not on your laptop)
--name my-spark-job Human-readable name for your job
--class com.example.MyJob The main class to run
spark.kubernetes.container.image Docker image containing Spark + your code
spark.executor.instances=3 Request 3 executor pods
spark.executor.memory=4g Each executor gets 4GB memory
spark.kubernetes.namespace Which K8s namespace to use
spark.kubernetes.authenticate... Service account for RBAC permissions
