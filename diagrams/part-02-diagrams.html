  • spark.kubernetes.driver.node.selector.node-type=driver
  • spark.kubernetes.executor.node.selector.node-type=executor
  • Taints prevent non-Spark pods from using Spark nodes
5. Verification Checklist

Cluster Setup Verification

  • ✓
    Nodes are Ready
    kubectl get nodes — All nodes show STATUS: Ready
  • ✓
    Spark Namespace Exists
    kubectl get namespace spark-jobs
  • ✓
    Spark Operator Running
    kubectl get pods -n spark-operator — Pod is Running
  • ✓
    Node Labels Correct
    kubectl get nodes --show-labels | grep spark-role
  • ✓
    Storage Classes Available
    kubectl get storageclass
  • ✓
    Test SparkPi Runs Successfully
    kubectl logs spark-pi-test-driver | grep "Pi is roughly"

Spark Pod Types

Pod Type Role Resource Profile Reliability Requirement

Executor Runs tasks, processes data High CPU, High Memory Medium (can be replaced)
